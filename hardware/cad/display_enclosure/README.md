# Indoor display enclosure

These files are the author's enclosure design for the indoor e-paper display, created in Autodesk Fusion 360 for the DFRobot FireBeetle 2 ESP32-E and 4.2-inch e-paper display.

- `display_enclosure.f3d` is the editable Fusion 360 source.
- `display_enclosure.stl` is the printable export.

This is not the outdoor sensing-node enclosure. The sensing enclosure's concept and functional requirements were developed through discussion involving the project author and Simon; Simon completed its detailed CAD design and 3D printing. Simon's CAD files are not included here.
